# 弹球入洞 - 经典形状大挑战

一款基于 HTML5 Canvas 的休闲弹球小游戏，参考经典弹球入洞玩法，无广告，纯单机体验。

## 玩法说明

1. **瞄准发射** - 拖动底部小球设定方向和力度，松手发射
2. **弹入通道** - 球在下方弹跳，需要瞄准让球进入形状下方的狭窄通道
3. **打破缺口** - 球通过通道打到金色缺口，反弹出来，金色消失缺口打开
4. **再次进入** - 球反弹后需要再次进入通道，这次通过打开的缺口进入形状内部
5. **蓝色得分** - 球在内部弹跳击中蓝色方块得分，缺口自动封闭
6. **加速反弹** - 连续 3 次击中蓝色方块（中间不碰墙壁），触发加速反弹，越打越爽！

## 游戏元素

- **黑色/白色墙体** - 小球碰撞反弹的边界
- **金色缺口** - 入口，需先击打破墙才能进入
- **蓝色方块** - 内部得分目标，击中后消失
- **白色小球** - 玩家发射的弹球

## 特性

- 无广告，纯游戏体验
- 支持鼠标和触屏操作
- 粒子特效、屏幕震动、发光效果
- Web Audio 音效（碰撞、击破、加速等）
- 响应式设计，适配手机和电脑

## 运行方式

直接用浏览器打开 `index.html` 即可游玩，无需安装任何依赖。
